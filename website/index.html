Projeto de laboratório. Toda a infraestrutura é provisionada com Terraform: frontend estático em um bucket S3 privado, servido pelo CloudFront (HTTPS com ACM, DNS no Route 53 e WAF), autenticação com Cognito, API com API Gateway, Lambda e DynamoDB, e um bucket S3 separado para mídia.
